디자인 기준 — 그룹 미션 클라이언트

시안 7장 · 프로토타입 · 플로우맵이 함께 쓰는 정본. 값을 바꿀 때는 이 파일을 먼저 고치고 시안을 따라 고친다. 구현에서는 이 값을 tailwind.config 의 theme 로 옮긴다.

라이트 · 다크(시스템 설정을 따름)외부 글꼴 없음 — 시스템 글꼴반응형 — 360 · 390 · 768 · 1280

방향

  • 시계가 주인공남은 시간 · 마감은 숫자로 크게, 고정폭 숫자(tabular-nums). 장식 그림은 쓰지 않는다. ← 07:00 시작 · 08:00 마감 · 08:00:03 유예
  • 아침의 한 색강조색은 해 뜨는 주황 한 가지. 주 버튼 · 지금 문제 · 내 줄에만 쓰고 넓은 면에는 쓰지 않는다.
  • 상태는 세 가지뿐진행 중(파랑) · 성공(초록) · 실패(빨강). 08:00 까지 3문제를 못 푼 그룹원도 결과에서는 「실패」. 상태 아이콘은 누르는 것처럼 보이면 안 된다(X 대신 팔각 느낌표 · 모래시계).
  • 현황판은 촘촘하게그룹원 10명이 한 화면에 들어가야 한다 — 줄 높이 40~46, 여백으로 멋을 내지 않는다.
  • 모바일 먼저390 폭 기준, 누르는 것은 높이 44 이상, 주 버튼은 아래쪽. PC 는 같은 부품을 다시 늘어놓을 뿐 새 부품을 만들지 않는다.
