**세 줄 요약**
- 기준 30개(O1~O30) + 워크트리 격리 3개(O31~O33) + 정답 정규화 2개(O34~O35) + 공통 오류 응답 4개(E1~E4) + 계약 정리 2개(C1~C2) + 불변식 2개(I1~I2) — 로컬 실행 계약(SPEC)과 저장소 설정, 기능들이 함께 쓰는 공통 코드 바탕(시각 주입 · Lua 로더 · 키 · 오류 코드), PostgreSQL 스키마 · 문제 시드, `worker: persister` 소비 루프와 dead-letter 가 Redis 가 빈 뒤의 재적재(LLD §4.2)가 「설계대로 됐다」를 판정한다.

## 3. 판정 밖
- NFR-1 ~ NFR-4 — 기능 구현과 함께 기능별 ORACLE 이 정한다. NFR-5 의 앱 부분 중 Redis 가 빈 뒤의 재적재는 이 문서 O22 ~ O30 이 정한다(v3.6 · v3.10). persister 가 아직 못 쓴 반영의 유실(Stream 이 함께 사라짐 — LLD §4.2)은 AOF 허용 유실(O3 · O4)과 같은 선이라 따로 재지 않는다.
