  description: |
    기능별 SPEC(`docs/spec/{auth-signup,game-session,solve-signal,realtime-board,deadline-result}.md`)과
    공통 규약(`docs/api-guide.md`)을 기계가 읽는 형태로 옮긴 계약이다. 둘이 어긋나면 SPEC 이 정본이다.
    구현 전 오퍼레이션은 `501 NOT_IMPLEMENTED` 를 돌려준다.

    - 주소: `api` 앱(:8080) `/api/v1/**` · `realtime` 앱(:8081) `/realtime/v1/**`(SSE). `x-app` 은 그 오퍼레이션을 서빙하는 앱이다(`api` · `realtime`).
    - 본문: 요청 · 응답 모두 `application/json; charset=utf-8`(SSE 는 `text/event-stream`). 모르는 요청 필드는 무시한다.
    - 시각: ISO-8601 · 오프셋 필수. 서버는 `+09:00`(KST)으로 보낸다(예: `2026-11-12T07:00:00+09:00`). 클라이언트가 보내는 시각(`successTime` · `clickedAt`)도 오프셋 필수.
      날짜는 `YYYY-MM-DD`(KST 게임 날짜).
    - 인증: HttpOnly 쿠키. 로그인 · refresh 가 `Set-Cookie: access=…; Path=/api`(1시간) · `refresh=…; Path=/api/v1/auth`(2시간)를 준다.
      토큰은 본문에 없다. 가입 · 로그인 · refresh 를 뺀 모든 `/api/v1/**` 는 `access` 쿠키가 없거나 만료 · 위조면 `401 UNAUTHORIZED`(가장 먼저 본다).
      `401` 이면 `POST /api/v1/auth/refresh` 한 번 → 또 `401` 이면 로그인 화면.
    - 실시간(SSE): `POST /api/v1/realtime/tickets` 로 받은 30초 1회용 티켓을 `?ticket=` 으로 넘긴다(EventSource 가 헤더 · 다른 출처 쿠키를 못 싣는다).
      메시지 형식은 `docs/api/asyncapi.yaml`.
    - 오류: 언제나 `{ "code": ErrorCode, "message": string }`. 클라이언트는 `code` 로만 분기한다. 코드별 HTTP 상태는 `ErrorCode` 스키마 설명(api-guide §4).
    - 멱등: 신호 API(진입 · 풀이 · 패스 · 실패)는 같은 요청을 다시 보내도 같은 결과를 준다 — 네트워크 오류 · 타임아웃이면 같은 본문으로 재시도한다.
    - 진행도: 응답의 `progress` 는 0~3. 미션 시작 전(내부 -1)은 0 으로 보내고 `started=false` 로 구분한다.

        - 정원은 전체 소속 인원 10명(AS6 — 07:00 이후 가입자도 센다).

          서버의 그룹 채널 구독이 끊겨도 `rankingFinal` 없이 정상 종료한다 — 끝난 스트림이 아니므로 새 티켓으로 다시 붙는다(RB7 · RB8).

          08:00 전 조기 확정은 즉시 `true`. 순위는 경쟁 순위(1, 1, 3), 같은 순위 안은 `userId` 바이트 순.
        - 이 API 는 `groupStatus` `IN_PROGRESS` 를 주지 않는다. `ranking[].status` 는 `SUCCEEDED` · `CHEAT_FAILED` · `FAILED` 뿐이다.
        - `nextGameStartAt` 은 서버 시각 기준 다음 07:00 KST(오늘 07:00 전이면 오늘, 아니면 내일 — DR10).

    # ── 공통 ──
    ErrorCode:
      type: string
      description: |
        오류 코드(api-guide §4). 클라이언트는 이 값으로만 분기한다. 코드 → HTTP 상태:
        - 400 `INVALID_REQUEST` — 본문 형식 · 필드 규칙 위반
        - 401 `UNAUTHORIZED` — access token 없음 · 만료 · 위조
        - 401 `INVALID_CREDENTIALS` — 로그인 아이디 · 비밀번호 불일치
        - 409 `ALREADY_LOGGED_IN` — 이 계정에 살아 있는 로그인(refresh token)이 있음
        - 409 `LOGIN_ID_TAKEN` — 가입 — 아이디 중복
        - 409 `GROUP_NAME_TAKEN` — 가입(새 그룹) — 그룹명 중복
        - 404 `GROUP_NOT_FOUND` — 가입(기존 그룹) — 그런 그룹 없음
        - 409 `GROUP_FULL` — 가입(기존 그룹) — 10명 참
        - 409 `GAME_NOT_OPEN` — 그 API 를 받는 시간이 아님
        - 403 `NOT_PARTICIPANT` — 그날 그룹원이 아님(07:00 이후 가입)
